# Security Policy

This project touches smart-home registration flows. Please keep reports and examples sanitized.

## Do Not Share Publicly

Do not include any of the following in issues, pull requests, screenshots, logs, or examples:

- Real apartment building/unit numbers.
- Real UUIDs registered to a wallpad.
- HDC/IPARK/BESTIN access tokens.
- One-time verification codes.
- Home Assistant `.storage` files.
- Screenshots showing private residence details.

## Responsible Use

Use this project only for a residence you own or are authorized to administer. Do not use it to enumerate apartment records, brute-force OTPs, or bypass wallpad approval.

## Reporting

If you find a security issue, open a minimal GitHub issue with sanitized reproduction steps, or contact the repository owner privately if available. Avoid posting live credentials or unit identifiers.
